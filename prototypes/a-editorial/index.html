02 Munkák / csak ellenőrzött esettanulmányok — kitalált eredmény nélkül
projekt státusz: élő

KIOSZ Pizza Napoletana

Élő rendelési rendszer — nem sablon. Böngészhető menü, kosár, vendég-checkout, valós nyomkövetés és tablet-first admin felület, egy közös API-n.

stack
  • frontendReact + TypeScript + Vite
  • backendPHP 8 + PDO REST API, framework nélkül — /api/v1/*
  • adatbázisMySQL / MariaDB, számozott migrációkkal
  • tartalomcontent-as-source-of-truth JSON pipeline — egy forrás generálja a DB seedet és a frontend adat-tükröt
folyamat
  1. menü böngészése
  2. extra hozzáadása
  3. vendégként checkout
  4. valós nyomkövető URL
  5. tablet-first admin fogadja és kezeli a rendelést

Szerepkör-alapú jogosultság: a kitchen_staff szerepkör helyesen nem fér hozzá a kedvezménykezeléshez.

verifikáció

Playwright E2E tesztek a valós, éles stack ellen — mock nélkül —, lefedve a teljes rendelési folyamatot (böngészés → extra → vendég-checkout → nyomkövetés → admin elfogadás). Reszponzív specifikáció ellenőrizve:

360 · 375 · 390 · 412 · 430 · 768 · 820 · 834 · 1024 · 1440 px

PHPUnit integrációs tesztek valós MariaDB teszt-adatbázis ellen — optimista zárolás, admin authentikáció.

galéria

192 fotós szerkesztői galéria öt szűrőben, 24-esével progresszíven betöltve, billentyűzettel is használható lightboxszal. Alább kontaktkép-rács helyőrzőkkel — a végleges buildben valós KIOSZ-fotókkal.

04 Rólam / munkamódszer, nem életrajz
daekon egyszemélyes

Egyszemélyes kreatív fejlesztőként dolgozom — nem egy 200 fős ügynökség vagyok, amelyik annak adja ki magát. Ez azt jelenti, hogy a specifikációtól a production tesztig ugyanaz a kéz nyúl hozzá a projekthez, és minden döntés visszakövethető.

A munkamódszerem a saját projektjeim dokumentációjából jött: számozott adatbázis-migrációk, valós stack elleni E2E tesztek, felelősség szerint szétválasztott admin jogosultságok. Ez az oldal is így épül — amit itt látsz, az a saját gyakorlatom, nem egy marketing-ígéret.

Amit nem csinálok: kitalált statisztikákat, kitalált ügyfeleket, kitalált eredményeket. Ha egy tény nincs ellenőrizve, nincs is fent az oldalon.
