# Kezelőfelület – rövid útmutató az ötvösnek

Belépés: a weboldal címe után írja be: `#/admin` (pl. `…/#/admin`), és mentse el könyvjelzőként. A jelszót külön kapja.

| Mit szeretne? | Lépések |
|---|---|
| **Árat módosítani** | Árak → írja át a számot → nézze meg a „Változtatások ellenőrzése” részt → **Árak mentése** → „Az árak sikeresen mentve.” |
| **Gyűrűt szerkeszteni** | Gyűrűk → keressen a cikkszámra → Megnyitás → módosítás → **Mentés** |
| **Fényképet cserélni** | Gyűrűk → a gyűrű megnyitása → **Fénykép cseréje** → nézze meg az előnézetet → **Új fénykép mentése** |
| **Érdeklődőt visszahívni** | Érdeklődések → **Felhívom** (tárcsáz) → beszélgetés után **Visszahívtam** |
| **Egyedi munkát bemutatni** | Műhelymunkák → **+ Új műhelymunka** → cím, leírás → **Fotók hozzáadása** → **Mentés** |

**Jó tudni**
- Ha tévedett egy árral: Árak → **Korábbi árak** → visszaállítás. Előtte megmutatjuk, mi változik.
- Amíg egy gyűrű adatai nincsenek jóváhagyva, a vásárló „Egyedi árajánlat”-ot lát. Ez nem hiba. A gyűrű adatlapján látszik, mi hiányzik.
- A „belső számított ár” csak tájékoztató, nem végleges: a vásárló nem látja.
- Ha valami nem mentődött el, piros üzenet jelzi. Ilyenkor semmi nem változott.
